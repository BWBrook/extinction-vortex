# Caribou descriptive deep dive (14 October 2026)

Accepted by Astra in board 1625, with Barry's decision of 14 October quoted in
board 1623. The evidence base is
`notes/astra_caribou_recovery_review_20261014.md` and
`notes/option3_recovery_matrix_20261013.md` §8.

| File | Content |
|---|---|
| `caribou_sources.json` | URLs, byte counts and SHA-256 of the pinned public snapshots, with Astra's hashes where she recorded them. Lamb files are pinned to Git `f069f1f6` only. The live WSI file hash differs from Astra's snapshot, but its 23 Individuals rows are identical to her receipt. The snapshots are kept outside the repository. |
| `make_caribou.py` | Builds the four generated tables (Maligne, Purcells Central, Banff, demographic evidence) and both figure formats from the snapshots. It refuses to run if a static snapshot's hash, or the WSI Individuals content hash, differs. Run with `uv run --with matplotlib python make_caribou.py SOURCE_DIR`. |
| `maligne_census.csv` | By year: Parks Canada fall flight dates, group records, sum of recorded totals and blank-total IDs, alongside the Lamb archive count and Williams ID 27 |
| `purcells_central_census.csv` | By year: WSI OTC, MNKA and MC (with BEST flags, detail IDs and notes) and the Lamb archive count |
| `banff_census.csv` | Williams ID 28 against the Lamb archive (16/16 match), with the 2008/2009 note |
| `demographic_evidence.csv` | Herd-year survival (est, sd) and calves per classified non-calf, each with a provenance note |
| `events_timeline.csv` | Dated, sourced events and interventions, with evidence tags and coding. Compiled by hand and source-checked; not generated by the script. |
| `conflict_register.md` | Value conflicts A1–A11, missing evidence B1–B6, and interpretation limits C |
| `caribou_case.png`, `caribou_case.pdf` | Three-panel small multiples: counts by source class, rugs for survival and composition years, and Banff event lines |

- The Maligne fall sums equal those in Astra's receipt: 2001 = 21,
  2003 = 24, 2004 = 11, 2008 = 6, 2014 = 4.
- Banff crosswalk: 16/16.
- WSI Individuals rows match Astra's receipt.
- The figure was inspected after rebuilding.

  imputed or fitted.

**Corrections, 15 October** (Astra's caribou artifact review,
`notes/astra_caribou_artifact_review_20261014.md`):
- Maligne composition is plotted and tabulated at its **survey calendar
  year**. The archive adds one to fall and spring survey years
  (`dataprep.Rmd` lines 849–853); the original archive year is kept as its own
  column.
- Survival archive-year conventions are stated in the figure: Maligne Y is
  about October Y−1 to September Y; Purcells Central Y is about April Y to
  March Y+1.
- Register A11 records the five Maligne compositions that differ from the
  same-year Parks flight.
- The WSI table keeps both `SUMMARY_DETAIL_NOTE` and `SUMMARY_GENERAL_NOTE`.
  Month and day are given as supplied, with a blank day where the source has
  none, instead of the invalid `YYYY-MM-00` placeholders.
- The live WSI response changes its whole-file hash between downloads, through
  generated feature IDs and timestamps. The build therefore checks a content
  hash of the 23 Individuals rows (`caribou_sources.json`), which is verified
  identical to Astra's receipt.
- Narrative, register A5 and timeline wording corrected:
  - panel references;
  - "not recovered in the inspected sources";
  - documented management during the represented decline;
  - the low OTC does not itself establish a drop.
